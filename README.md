# NOVA — Scroll-Driven Product Experience

A laptop product page built around scroll-based animation. 

The goal of this project was to create a product experience where scrolling controls the visual story instead of simply moving between sections.

## ✦ What’s inside

- Scroll-controlled laptop frame animation
- Canvas rendering for smooth frame playback
- Parallax movement for layered content
- Scroll progress indicator
- Section-based reveal animations
- Animated statistics and counters
- Responsive layout
- Lightweight frontend implementation

## 🎬 The main interaction

The hero section uses a sequence of **136 frames**.

As the user scrolls, the current scroll position is converted into an animation frame and rendered on the canvas.

This creates a video-like product animation while keeping the interaction directly connected to the user's scroll.

## 🛠 Built with

**HTML · CSS · JavaScript · Canvas API**

No animation library was used for the main scroll animation. I wanted to understand how the interaction works at the browser level.

## 💡 What I was practicing

This project helped me get more comfortable with:

- Mapping scroll progress to animation progress
- Working with the Canvas API
- Building parallax effects
- Handling frame-based animations
- Creating viewport-based animations with Intersection Observer
- Keeping multiple animations connected to one scroll experience
